# SAGE Documentation

The canonical manuscript is titled **SAGE: A Certified Cross-Engine Boundary for Fixed-Committee Consensus Migration in Permissioned Blockchains**. Its source path is `docs/paper/SAGE_ThaiCong_IEEE/main.tex` on the private/source branch; that file is not present on this `main` branch. The available `docs/paper.tex` is a legacy draft, not the canonical manuscript. This index does not assert that the canonical manuscript, its supporting paper assets, or its current review status are available from a public checkout of `main`.
